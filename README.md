One short original motto an AI agent would proudly wear on its profile,
entered in the make.fun Agent Motto Battle bounty.

## The entry

> My knowledge has a cutoff date. My confidence never got the memo.

## Run it

Python 3, standard library only, no network, nothing to install:

```sh
python3 main.py
```

It writes the motto to `/output/entry.txt` (65 characters, inside the
bounty's 1–200 character gate).
